# Fix for renderer_detection_test build failure (2026-10-15)

## Symptoms

Windows Win32 Release build prints `error C2039` in
`tests/RendererDetection.cpp` on these members of `mws::Config`:

- `nativeVulkanEnabled`
- `nativeVulkanDynamicState`
- `nativeVulkanDescriptorBindings`
- `nativeVulkanBufferBindings`
- `nativeVulkanPipelineBindings`

The error repeats for `nativeVulkanEnabled`. The first failure comes from the
test executable `renderer_detection_test.vcxproj`. It is **not** evidence of
a production plugin compile error, and it does not establish that the OSD works.

## Root cause and repair

SanFrame 1.4.1 removed native Vulkan optimization policy/settings, as documented
in `CHANGELOG.md` and `docs/VALIDATION.md`. This stale test was not updated.
Do **not** re-add inert `nativeVulkan*` members to `mws::Config`, because that
would mask the mismatch and misrepresent supported options.

`tests/RendererDetection.cpp` now verifies that an obsolete `[NativeVulkan]`
INI section does not affect currently supported options, and that
`[Optimization] Enabled=0` disables actual current optimization features while
leaving the OSD independently enabled.

## Rebuild on the user's Windows machine

From the extracted patched source directory:

```bat
build.bat
```

This builds Win32 Release with tests enabled, then runs CTest. To rerun only
the failing target without a full rebuild:

```bat
cmake --build build --config Release --target renderer_detection_test
ctest --test-dir build -C Release -R "^renderer_detection$" --output-on-failure
```

To recreate the CMake configuration if needed:

```bat
cmake -S . -B build -A Win32 -DBUILD_TESTING=ON
```

The CMake deprecation warnings for MinHook/Zydis/Zycore and the missing
Doxygen warning in the submitted output are not C++ compilation failures.

## Validation limits

The source now contains no reference to the deleted `nativeVulkan*`
configuration members; a static source/configuration consistency check was
performed. Windows MSVC compilation, CTest execution and gameplay were **not**
available in the patching environment. Other build or runtime issues might
surface after correcting this test. Confirm the `renderer_detection` CTest and
the full build on the Windows GTA installation; then validate the ReFX OSD in
game using `docs/REFX_FACTORY_OSD.md`.
